# Warehouse Forklift Operations Dashboard

Streamlit dashboard for forklift productivity, shift performance and staff rosters.

> **Demo data:** all figures are generated in `app.py` (fixed seed) — there is no live IoT/sensor feed yet. See `Forklift Dashboard PRD.md` for the original spec.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
